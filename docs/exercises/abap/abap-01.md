Erstelle die ausführbare Klasse `ZCL_???_ABAP_01` mit Hilfe der abgebildeten Informationen wie folgt:
- Erstelle Datenobjekte, um Informationen zu einem Film zu speichern
- Weise den Datenobjekte Werte zu
- Gib die Inhalte der Datenobjekte auf dem Bildschirm aus

## Informationen zu den Datenobjekten

| Datenobjekt     | Datentyp      |
| --------------- | ------------- |
| title           | c (Länge: 50) |
| genre           | c (Länge: 10) |
| publishing_year | n (Länge: 4)  |
| runtime_in_min  | i             |

## Beispielhafte Konsolenausgabe

```
Title: Fight Club
Genre: Thriller
Publishing Year: 1999
Runtime in Minutes: 139
```
