Das _ABAP RESTful Application Programming Model_ (RAP) ist ein Programmiermodell für die End-to-End-Entwicklung von OData-basierten Webanwendungen in SAP S/4HANA (Cloud). Es unterstützt sowohl die Entwicklung transaktionaler Fiori Elements Apps als auch die Veröffentlichung von Web APIs.

- [RAP Business Objects](rap-bos.md) – Datenmodell, Verhalten und Implementierungsarten
- [Laufzeitartefakte](runtime-artifacts.md) – alle Entwicklungsobjekte einer RAP-Anwendung im Überblick
- [Entity Manipulation Language (EML)](eml.md) – programmatischer Zugriff auf RAP BOs aus ABAP
